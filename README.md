# Hellopimmi — Pim Hanwong’s portfolio

One-page portfolio for social media, content strategy, brand storytelling, and paid media.

## Publish on Cloudflare Pages

Connect this repository to Cloudflare Pages. Choose no framework, no build command, and the repository root as the output directory. Request the project name `pimmi` if available.

## Publish on GitHub Pages

In Settings → Pages, select **Deploy from a branch**, choose **main** and **/ (root)**, then save.

## Files

`index.html`, `style.css`, and `script.js` are the editable site source. Images are stored beside them for a build-free deployment. Double hyphens in image names indicate their original project folder.

Campaign offers and engagement figures are historical, as captured in the portfolio. Personal TikTok view counts are dated on the page.
